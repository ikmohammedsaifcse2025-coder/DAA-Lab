# DAA Lab Programs (CS5303)

Python implementations for the first 5 experiments of the Design and Analysis of Algorithms (CS5303) lab — Chennai Institute of Technology.

| # | File | Topic |
|---|------|-------|
| 1 | `1_interpolation_search.py` | Interpolation Search vs Binary Search |
| 2 | `2_string_matching.py` | Naive, KMP, and Rabin-Karp string matching |
| 3 | `3_kruskal_prim_mst.py` | Kruskal's & Prim's Minimum Spanning Tree |
| 4 | `4_dijkstra_shortest_path.py` | Dijkstra's Single Source Shortest Path |
| 5 | `5_min_max_divide_conquer.py` | Min-Max using Divide and Conquer |

## How to run
Each file is standalone. Run any one with:

```bash
python3 1_interpolation_search.py
```

No external libraries required — only the Python standard library (`heapq`, `random`, `time`).
